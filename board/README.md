# 开发板改装：外接 WS2812 状态灯

板载红灯是电源指示灯，软件无法控制，所以外接一颗 **WS2812** 模块当状态灯。显示规则见根目录 [README 的“LED 状态灯”](../README.md#led-状态灯)，这里只讲怎么接线、焊接。

设计取舍：**板子上不焊任何东西，也没有飞线和分立元件**，整个改装只有“板子 + 2×3 排母 + 3 根线 + 模块”。

## 材料

| 项目 | 说明 |
| --- | --- |
| WS2812 模块 | 带去耦电容的单颗模块，如 SparkFun BOB-13282（17.78 × 12.7 mm，板上有 0.1 µF 电容、2 个安装孔，开源设计见 [sparkfun/WS2812_Breakout](https://github.com/sparkfun/WS2812_Breakout/tree/V_1.1b)）。型号未定，下面以“VCC / GND / DIN”泛指模块的三个引脚 |
| 2.54 mm **2×3 排母** | 直插式，镀金，带塑料座。尾针（焊线的一端）约 3 mm |
| 线 | 3 根，26-28 AWG 软硅胶线，红／黑／另一色（数据） |
| 热缩管、热熔胶 | 套焊点、固定线 |
| 万用表 | 装之前和上电前的两次检查 |

开发板 J4 排针已经是镀金公针（2×13，间距 2.54 mm），排母直接插上去，不需要焊板子。

## 接线

排母插在 J4 **最上面三行**（靠近 H2 模块的一端），共盖住 1-6 脚。只用其中**内列**（偶数脚）三个触点；外列三个触点只起固定作用，**不接线**。

```
(上方是 H2 模块)         外列(奇)   内列(偶)
                         板子左边缘 → 板子中心
  行 1 (最上)             1 GND      2 GND      ← 接线
  行 2                    3 5V       4 3V3      ← 接线
  行 3                    5 GPIO15   6 GPIO16   ← 接线
```

| 排针脚 | 信号 | 线色 | 模块端 |
| --- | --- | --- | --- |
| 2 | GND | 黑 | GND |
| 4 | 3V3 | 红 | VCC（5V/VDD） |
| 6 | GPIO16 | 另一色 | DIN（Data In），**不接 DOUT** |

- **供电用 3V3，不要用 5V。** 排针上 3 脚是 5V，和 4 脚（3V3）并排；WS2812 的数据线高电平门限是 0.7×VDD，5V 供电时 S3 的 3.3V 输出不够，会偶发乱色。代价是 3.3V 低于 WS2812 标称的 3.5V，**蓝色会偏暗、黄色会偏绿**，固件里要调色值（见根 README）。
- 引脚位置来自 Espressif 原理图和 3D 模型，装之前仍要用万用表确认（见下）。
- 数据线上不加电阻，靠线短来保证信号质量：**每根线 4-5 cm，最长不超过 10 cm**。去耦电容靠模块自带的；3V3 轨在板上的 LDO 旁边已有 10 µF + 0.1 µF。

## 焊接步骤

### 1. 处理排母外列尾针

把外列（1、3、5 脚）三个尾针用斜口钳**剪到几乎和塑料座平齐**。它们不接线，其中 3 脚对应 5V、紧挨着 4 脚的 3V3 焊点，剪掉后线头和焊锡就碰不到它。剪尾针不影响插座抓住公针。

### 2. 焊线到排母

1. 三根线各剥 2 mm，镀锡。
2. 分别焊到内列三个尾针：行 1（GND）接黑线，行 2（3V3）接红线，行 3（GPIO16）接数据线。
3. 每个焊点套热缩管；线从插座**同一侧**引出。

### 3. 焊线到模块

1. 线另一端剥 2 mm，镀锡。
2. 按上表焊到模块的 **VCC / GND / DIN** 通孔焊盘，注意看模块丝印，不同厂家的引脚顺序不同。
3. 如果模块有 DOUT，不接，也不需要接任何东西。

### 4. 装前检查（还没插到板子上）

用万用表蜂鸣档量排母上三根线对应的焊点，**两两之间都不应该导通**：GND-VCC、GND-DIN、VCC-DIN。

### 5. 插到板子上

1. 板子断电，排母**行 1 对准 J4 最上面一行**（离 H2 模块最近的一行），内列对准内侧一列（靠板子中心）。
2. 垂直压到底，插到公针根部。
3. 上电，不烧固件也可以：用万用表量模块 VCC 对 GND 应该是 **3.3 V**。量完再断电。

## 固定

排母靠摩擦力抓针，**外壳要把它压住并限位**，否则振动和线的拉力会让接触变差：

- 盖子压住排母顶面，两端的挡墙卡住塑料座，不让它沿排针方向滑动。
- 线出口留出应力释放，线不要直接拉着焊点；焊点和热缩管根部点一点热熔胶。
- 模块贴在盖子内侧，正对排母上方的开孔，线 4-5 cm 就够到。

## 尺寸（供外壳设计）

数据来自官方 3D 模型，原点在板子左下角，H2 在上，USB 在右，详见 [docs/reference/README.md](../docs/reference/README.md)。

| 项目 | 数值 |
| --- | --- |
| PCB | 51 × 51 mm（含天线 51.4 × 62.6 mm），**没有安装孔**，PCB 厚度需实测 |
| J4 排针 | 2×13，列中心 x = 2.77（外，奇数脚）/ 5.31（内，偶数脚）；行中心 y = 2.59 + 2.54k，最上一行 y = 33.07 |
| 2×3 排母占位 | x 1.5-6.6，y 26.7-34.3；插上后从板面起约 **14 mm**，是板上最高的东西（其余元件都不超过 3.5 mm） |
| 模块位置 | 盖子内侧，正对 x ≈ 4-5、y ≈ 30 |
| 开孔 | 完全镂空，不留扩散片；亮度由固件限制 |

排母和模块的实际高度、PCB 厚度请实测后补进外壳参数。
